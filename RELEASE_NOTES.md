# Release Notes - Версия 2.0.0

## Основные изменения

### 1. Миграция Python 3.10 → 3.13

**Изменения:**
- Обновлены все зависимости под новую версию `backend/requirements.txt`
- Всё отрефакторил для совместимости всех либ с Python 3.13

**Требования:**
- Python 3.13 или выше
- PostgreSQL
- Node.js 18+

---

### 2. Реорганизация структуры проекта

**До:**
```
project/
├── main.py
├── requirements.txt
├── website/
└── templates/
```

**После:**
```
project/
├── backend/
│   ├── main.py
│   ├── requirements.txt
│   ├── website/
│   └── telegram_bot/
└── frontend/
    ├── package.json
    ├── app/
    └── components/
```

**Изменения:**
- Все файлы логики перенес в `backend/`
- Frontend выделил в отдельную директорию `frontend/`
---

### 3. Миграция фронтенда на Next.js 14

**До:** Flask шаблонизатор (Jinja2)

**Теперь:** Next.js 14 с TypeScript и React

**Причины:**
- Server-Side Rendering (SSR)
- TypeScript для типобезопасности
- Приятный UI с Tailwind CSS

---

## Миграция с предыдущей версии

### Шаги для обновления:

1. **Обновить Python до 3.13:**
   ```bash
   python --version  # Проверьте версию
   ```
   Убетиться что Python 3.13 установлен

2. **Обновить код:**
   ```bash
   git pull origin main
   git checkout v2.0.0
   ```

3. **Переустановить зависимости:**
   ```bash
   cd backend
   pip install -r requirements.txt
   
   cd ../frontend
   npm install
   ```

4. **Запуск:**
   ```bash
   # Backend
   cd backend
   python main.py
   
   # Frontend (в другом терминале)
   cd frontend
   npm run dev
   ```
